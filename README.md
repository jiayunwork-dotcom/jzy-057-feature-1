# CollabMD — 多人实时协作 Markdown 文档平台

面向技术文档编写与评审的全栈应用：

- **实时协作内核（CRDT / RGA）**：每个字符带全局唯一 ID 与逻辑时钟，并发插入按 ID 稳定排序，删除保留墓碑（tombstone），任意操作顺序都收敛到同一文本；断网修改重连后自动合并。
- **协作呈现**：WebSocket 实时同步，彩色远程光标与选区高亮，在线协作者面板。
- **跨文档活引用**：选中一段正文登记为”可引用片段”后，任何文档都能插入指向它的引用块；源码区是一个紧凑标记，预览区渲染来源片段的当前内容并带来源标识。源片段被编辑时所有引用处实时跟随（精准推送，不广播）；片段被删除时引用降级为”已失效”并保留最后内容；建立引用时拒绝直接/间接成环；看不到来源文档的人只会看到”无权查看此引用来源”。
- **批注评审**：选中文本即可贴着正文加批注，支持回复线程、待处理 / 已解决 / 重新打开；批注锚点随正文移动，部分改动跟随最近匹配，整段删除标记为”锚点丢失”而不消失。
- **版本管理**：有变更时自动生成增量版本，随时手动命名快照；快照间行级 diff + 行内字符级高亮；回滚到任意快照且回滚本身是新版本，不丢中间改动。
- **权限**：所有者 / 编辑者 / 评审者 / 只读者四种角色。

## 架构

```
packages/
  core/        纯 TypeScript 内核（无 IO 依赖，前后端共用，单测覆盖核心性质）
    src/crdt/      CRDT 合并内核（RGA：字符 ID、逻辑时钟、墓碑）
    src/anchor/    批注锚定与跟随
    src/ref/       活引用：紧凑标记语法、依赖图成环检测、引用锚跟随、预览展开
    src/diff/      行级 + 字符级 diff
    src/version/   版本回放 / 快照 / 回滚
  api/         Fastify + ws 后端：REST 接口层 + WebSocket 实时网关 + Postgres + Redis
    src/realtime/DocumentRoom.ts       单篇文档的收敛权威（原有边界）
    src/realtime/ReferenceCoordinator.ts
        跨文档层：引用依赖关系维护、锚跟随、精准传播、按观看者权限生成快照
    src/services/excerptService.ts     片段登记 / 注销
    src/routes/reference.routes.ts     片段与引用块的 REST 接口
  web/         React + TypeScript + Vite：编辑器 / 预览 / 光标层 / 批注面板 / 版本历史
```

协作内核、批注锚定、版本 diff/回滚、跨文档引用各自独立成模块；跨文档层挂在单文档房间之上（订阅房间的 ops 事件），不改动单文档合并逻辑；接口层与实时网关单独成层。

## 一键启动

```bash
docker compose up --build
# 前端 http://localhost:8080
# 后端 http://localhost:4000
```

数据库在首次启动时自动建表并写入演示文件夹 / 文档与四个演示账号：

| 用户名 | 密码 | 角色 |
| --- | --- | --- |
| `owner` | `owner123` | 所有者 |
| `editor` | `editor123` | 编辑者 |
| `reviewer` | `reviewer123` | 评审者（只能批注） |
| `viewer` | `viewer123` | 只读者 |

用两个不同浏览器（或一个普通窗口 + 一个无痕窗口）分别登录不同账号，打开同一篇文档即可看到实时协作。

### 走通跨文档活引用

1. 打开《CollabMD 快速上手》，选中「部署前置条件」下的列表段落，点击源码区右上角的 **「登记为引用片段」**。
2. 打开（或新建）另一篇文档，点击 **「插入引用」**，选择来源文档与刚登记的片段，预览区即出现带来源标识的引用块。
3. 回到源文档修改那段正文 —— 引用方的引用块在不刷新页面的情况下实时更新。
4. 把源片段整段删除 —— 引用块降级为「已失效」，保留最后可见内容。
5. 用 `viewer` / `reviewer` 账号打开《接口草案（编辑者所有）》：来自《内部规范（仅所有者）》的引用只显示「🔒 无权查看此引用来源」，看不到真实内容。

## 本地测试

```bash
npm install
npm test
```

测试覆盖：CRDT 收敛（任意操作顺序逐字符相同）、并发插入 + 删除同位置、离线合并不丢改动、批注锚点随前方插入移动 / 部分改动跟随 / 整段删除标记丢失、版本增量累积 / 快照命名 / 两版本 diff / 回滚成新版本，以及跨文档活引用：源编辑后引用方逐字一致、前方插入不错位、整段删除降级保留最后内容、直接/间接成环被拒、无源文档权限拿不到引用内容、实时通道精准推送（只惊动受影响的文档会话）、重启后引用关系恢复。

## 端口

- `8080`：前端（Nginx，同时反代 `/api` 与 `/ws`）
- `4000`：API + WebSocket
- `5432`：postgres:16-alpine
- `6379`：redis:7-alpine
