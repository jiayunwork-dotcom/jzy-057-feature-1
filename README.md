# CollabMD — 多人实时协作 Markdown 文档平台

面向技术文档编写与评审的全栈应用：

- **实时协作内核（CRDT / RGA）**：每个字符带全局唯一 ID 与逻辑时钟，并发插入按 ID 稳定排序，删除保留墓碑（tombstone），任意操作顺序都收敛到同一文本；断网修改重连后自动合并。
- **协作呈现**：WebSocket 实时同步，彩色远程光标与选区高亮，在线协作者面板。
- **批注评审**：选中文本即可贴着正文加批注，支持回复线程、待处理 / 已解决 / 重新打开；批注锚点随正文移动，部分改动跟随最近匹配，整段删除标记为“锚点丢失”而不消失。
- **版本管理**：有变更时自动生成增量版本，随时手动命名快照；快照间行级 diff + 行内字符级高亮；回滚到任意快照且回滚本身是新版本，不丢中间改动。
- **权限**：所有者 / 编辑者 / 评审者 / 只读者四种角色。

## 架构

```
packages/
  core/        纯 TypeScript 内核（无 IO 依赖，前后端共用，单测覆盖核心性质）
    src/crdt/      CRDT 合并内核（RGA：字符 ID、逻辑时钟、墓碑）
    src/anchor/    批注锚定与跟随
    src/diff/      行级 + 字符级 diff
    src/version/   版本回放 / 快照 / 回滚
  api/         Fastify + ws 后端：REST 接口层 + WebSocket 实时网关 + Postgres + Redis
  web/         React + TypeScript + Vite：编辑器 / 预览 / 光标层 / 批注面板 / 版本历史
```

协作内核、批注锚定、版本 diff/回滚各自独立成模块；接口层与实时网关单独成层。

## 一键启动

```bash
docker compose up --build
# 前端 http://localhost:8080
# 后端 http://localhost:4000
```

数据库在首次启动时自动建表并写入演示文件夹 / 文档与四个演示账号：

| 用户名 | 密码 | 角色 |
| --- | --- | --- |
| `owner` | `owner123` | 所有者 |
| `editor` | `editor123` | 编辑者 |
| `reviewer` | `reviewer123` | 评审者（只能批注） |
| `viewer` | `viewer123` | 只读者 |

用两个不同浏览器（或一个普通窗口 + 一个无痕窗口）分别登录不同账号，打开同一篇文档即可看到实时协作。

## 本地测试

```bash
npm install
npm test
```

测试覆盖：CRDT 收敛（任意操作顺序逐字符相同）、并发插入 + 删除同位置、离线合并不丢改动、批注锚点随前方插入移动 / 部分改动跟随 / 整段删除标记丢失、版本增量累积 / 快照命名 / 两版本 diff / 回滚成新版本。

## 端口

- `8080`：前端（Nginx，同时反代 `/api` 与 `/ws`）
- `4000`：API + WebSocket
- `5432`：postgres:16-alpine
- `6379`：redis:7-alpine
